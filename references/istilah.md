# Istilah

## Cara memilih istilah

Urutan rujukan: aturan proyek atau sumber dokumen dulu, lalu tabel di file ini, lalu rujukan luar (Microsoft Terminology, Pasti).

1. **Ikuti sumbernya.** Nama yang tampil di aplikasi, dokumen sumber, atau kontrak ditulis persis seperti aslinya, termasuk huruf besar dan bahasanya. Contoh: tombol berlabel "Save" ditulis "Save", bukan "Simpan". Pembaca mencari kata itu di layar.
2. **Elemen antarmuka tanpa label sumber** memakai istilah di tabel bawah. Bila istilah Inggris sudah lazim dipakai tim, tulis dalam bahasa Inggris; jangan menerjemahkannya agar pembaca tidak perlu menebak.
3. **Istilah baru** dicari dulu di [Microsoft Terminology](https://learn.microsoft.com/en-us/globalization/reference/microsoft-terminology) dan aplikasi Pasti (Badan Bahasa). Pakai padanan yang sudah lazim; hindari padanan yang membuat pembaca menerjemahkan balik.
4. **Satu istilah, satu bentuk.** Tambahkan keputusan baru ke tabel ini, dan pakai bentuk yang sama di seluruh dokumen.

## Kata sulit yang diganti

| Sulit | Ganti dengan |
|---|---|
| dipalsukan, ditiru, atas nama orang lain | tulis kejadiannya, mis. "meminta data 'sebagai Admin' tidak menambah akses" |
| disaring (arti dibatasi) | dibatasi, tidak ditampilkan |
| tersamarkan | ditutupi, tidak ditampilkan |
| ditolak (403) | ditolak dengan kode 403 |
| respons jaringan | respons pada tab Network di browser |
| menembak endpoint | mengirim request langsung ke alamat API |
| eksekusi | menjalankan |
| implementasi (kata kerja) | membuat, memasang, menerapkan |
