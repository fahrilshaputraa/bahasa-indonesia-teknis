# Kalimat

## Pola dasar

- Mulai dari hasil atau tindakan, bukan pengantar.
- Kalimat aktif dengan pelaku yang jelas.
  - Sebelum: Konfigurasi dilakukan penyimpanan oleh Admin.
  - Sesudah: Admin menyimpan konfigurasi.
- Satu kalimat memuat satu gagasan. Bila melewati sekitar 25 kata, pecah.
- Sebut hal konkret: nama menu, tombol, angka, dan akun.
  - Sebelum: Lakukan penyimpanan data.
  - Sesudah: Klik Simpan.
- Fakta, dugaan, dan saran ditulis terpisah dan diberi label.
- Variasikan awal kalimat; jangan memulai semua kalimat dengan pola yang sama ("Anda dapat…", "Untuk…").

## Kata yang kaku

| Kaku | Lebih alami |
|---|---|
| melakukan pengecekan | mengecek |
| melakukan penambahan | menambahkan |
| melakukan pengujian | menguji |
| memberikan penjelasan | menjelaskan |
| terdapat | ada |
| pada saat ini | sekarang |
| dalam rangka untuk | untuk |
| hal ini dikarenakan | ini terjadi karena |
| dapat dilakukan dengan cara | caranya |
| yang mana, di mana (terjemahan which/where) | yang, tempat, ketika |
| sebuah (di depan setiap benda) | dihilangkan |

## Kata pengisi

Hapus kata yang tidak menambah informasi pada prosedur dan pesan:

| Hapus | Alasan |
|---|---|
| silakan, mohon (berulang di setiap langkah) | perintah langsung sudah sopan: "Klik Simpan" |
| mudah, cukup, hanya tinggal, dengan cepat | meremehkan pembaca yang kesulitan |
| tanda seru | nada berlebihan |
| perlu diketahui bahwa, dapat dikatakan bahwa | pengantar kosong |

## Ejaan yang sering salah

| Salah | Benar |
|---|---|
| analisa | analisis |
| silahkan | silakan |
| nampak | tampak |
| ijin | izin |
| resiko | risiko |
| aktifitas | aktivitas |
| merubah, dirubah | mengubah, diubah |
| praktek | praktik |
| dimana (kata tanya) | di mana |
| diantara | di antara |

Awalan **di-** disambung dengan kata kerja (`disimpan`), sedangkan kata depan **di** dipisah (`di folder`). Bila "di" bisa diganti "ke" atau "dari", tulis terpisah.

Unsur Indonesia yang dirangkai dengan unsur asing memakai tanda hubung: `di-deploy`, `commit-nya`.
